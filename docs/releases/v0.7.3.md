## Changes in v0.7.3

- Windows compiler selection keeps TeX tools in one working installation and prefers app-managed full LaTeX. Failed or hung system probes are skipped.
- **Account > Compiler > Clear compiler caches** resets build outputs and downloaded packages while retaining documents and installed compilers.
- Concurrent launches hand over to one app, including startup while the first instance is still initializing. Background reopen and update restart retain one sync worker.
- Setup/MSI upgrades preserve local data. **Explicit uninstall removes app-owned local data, compiler installations, credentials and login startup.** Linked folders and separately installed TeX are retained.
- Windows checks gate releases; timing-dependent UI diagnostics report warnings and keep their logs.

## Test this release

1. Install over an older setup/MSI and confirm projects and sign-in survive.
2. Compile a small document, clear compiler caches from Account, and compile again. If system TeX remains broken, install full LaTeX from Account.
3. Launch repeatedly, close the editor to the tray and reopen; confirm only one tray icon remains.
4. On a disposable profile, uninstall and reinstall; app-owned state should be fresh and linked project folders should remain.
