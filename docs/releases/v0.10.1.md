## Changes in v0.10.1

- **Import ZIP from the projects home.** Start a project directly from an Overleaf or other source ZIP, alongside Open folder, Join with ID and New project. The archive is selected before creation; projects with several main documents retain the main-file preview.
- **Locally supplied projects build without co-authors.** Creating a project from a folder now initializes its file list correctly. Local creation evidence, imported sources and completeness are saved before success is reported, and survive reopening and desktop worker restarts.
- **Input recovery explains the actual problem.** Local file-list and storage failures offer local retry or source restoration rather than requiring a co-author. Explicit restoration retains available previous data in Recovery. Missing compiler packages remain separate from missing project inputs.

The separate report of connected co-authors without source synchronization remains under investigation; this release does not claim to resolve that network incident.
